- **Live (all at 100%, `main` = `beta` in source code):** router **1.5.18** (feature 011, both parts; merged into `beta` by PR #103 with all 13 checks green, Code quality green again on the merge commit, then merged into `main` on 2026-10-23, signed and published at 0% and raised to 100% on the owner's order; `verify_release.py` 0 FAIL, 0 WARN, 12 PASS). What it does. **Part A:** the first setup no longer needs the router's own internet. The setup program on the computer reads the router, works out which of `opennds curl ca-bundle jsonfilter libmicrohttpd-no-ssl` it is missing, downloads them and the installer from the router's **own** package sources (`/etc/opkg/distfeeds.conf`), copies the bundle into `/tmp/piso-offline/` over SSH, and the router checks each source's `Packages` with its own `usign` and keys and each package's sha256 before one `opkg install`; `install.sh --local` and `PISO_LOCAL_PKGS` skip the ping and `opkg update`. If the bundle cannot be prepared (no signed indexes, an apk router, too little memory, a package it cannot fetch) it says why and falls back to today's online path; with no internet either it stops **before changing the router** and names both reasons. `--router-online` skips the offline path. The bundle lives only in RAM and is deleted over SSH afterwards, success or not. **Part B:** every router's coin box network gets a name of its own. `piso-setup box-wifi-name` moves an older router (or one whose rotation failed) from the shared `PisoCoinBox` to `PisoCoinBox-<id>` with a new password, telling the box first and switching the router after; `piso-setup status`, the setup summary and the setup program's Check-up say when a router still has the shared name and name the command; the pairing tips and the "did not join" message say another PisoHub router nearby may be answering. It also fixes a latent fault: a box that refused its new Wi-Fi used to leave `BOX_WIFI_ROTATED` at 0, so `box_wifi_key` then named the wrong password. Firmware is not changed (the box already takes `wifi_ssid` and `wifi_pass` in one `/save`, and validates neither, so the command checks the name itself). Money and time code is not touched; during the switch the box is off its network for up to four minutes and its own flash queue keeps every coin, credited once afterwards. **What was feature 012 is part B of 011**; the number 012 is retired and its branch `feat/012-box-network-name` is kept only as a record. **Hardware: RS36 and RS37 were run by the owner on 2026-10-23 and reported passed**, RS37 (a)'s coin during the switch included; their per-step output is still to be pasted into `specs/features/ARCHIVE.md` (011-offline-setup). **Still not exercised anywhere:** BusyBox `ash` for the new the copied-packages script (removed) (only dash, ShellCheck clean for POSIX sh), real OpenWrt package indexes beyond two fixture sets, real `usign` signatures, https source downloads, and apk-based OpenWrt 25.x (refused by design). The installer is now **1635 KB of its 1700 KB budget**.
