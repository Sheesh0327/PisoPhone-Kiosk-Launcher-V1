# Filipino wording for owner sign-off (feature 049, Q6)

Generated from `tools/pisoportal/src/brand_fil.js`. **Read every row. The router release stays at 0% until you have signed this off** (`validation.md`, Gates). Change any row you do not like and I put it into the file; the tests then run again.

What it covers: the words the guest page writes by itself when the customer taps **Filipino**. The shop owner's own texts (tagline, welcome, promo, rules, contact, hours) are written by the shop in both languages and are not here. The spoken beeps and voice (“Insert coin now”, “5 pesos”) stay English. The saved voucher file stays English. Product names (HyperSpeed, Endurance), ₱, Wi-Fi, Mbps, GB, MB and the credit stay as they are. Durations: “3 hrs” becomes “3 oras”, “min” stays.
