---
name: sdd-handoff
description: Write a short handoff note before ending a chat so the next chat can start from files instead of history. Use at the turn or token limit or when the owner says to stop.
---
Write `specs/notes/YYYY-MM-DD_<feature>.md` (under one page): branch and last commit, what is done, decisions, what is open, the next step, and how to run the slow tests. Update `specs/STATUS.md`. Commit it. Tell the owner the prompt to paste into the new chat: read `constitution.md`, `CLAUDE.md`, `specs/README.md`, `specs/STATUS.md` and the note, then continue.
