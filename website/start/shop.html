Set up a shop

One program writes the coin box, sets up the router and pairs them. About 15 minutes for a unit.

You need: an ESP32 coin box board and a USB data cable; an OpenWrt router (for example the 360T6M), factory reset; a modem that is online; two network cables; a computer to run the program (Windows, macOS or Linux, Python 3.8 or newer); your own phone to open the setup page.

Before you begin: the router needs internet for the first setup. Plug the modem into the router's WAN port and check that the modem is online. The router downloads its own software during the setup; with no internet it cannot be set up at all, and the program stops and tells you so before it changes anything on the router. Replacing a router, or changing the modem? Get the new modem online first.
  1. Download and run the setup program. pisophone_setup.py, then python3 pisophone_setup.py (Windows: py pisophone_setup.py). It installs what it is missing.
  2. Open the address it prints on your phone (or scan the QR code it draws) and type the PIN shown in the terminal.
  3. Cable it as in the picture (the modem must be online: the router needs internet for the first setup) and reset the router. The program finds the router by itself.
  4. Type the shop's name and its public Wi-Fi name. Passwords are made for you and saved on a printable sheet; nothing to type.
  5. Plug the coin box into the computer by USB, tap Start the installation and wait about 10 minutes.
  6. Insert a coin to test, join the customer Wi-Fi with a phone, and print the sheet. Then add your phones.
My phone cannot open the page

The page is served by the setup computer, so the phone must be on a network that reaches it. A factory-reset router has no Wi-Fi yet, so the phone cannot use that one. Either give the setup computer a second connection (its own Wi-Fi or another Ethernet port) on your own network and put the phone on that network too, keeping the cable to the router plugged in; or open http://127.0.0.1:8765 in the computer's own browser.

A firewall may block port 8765 (--port changes it).

Is everything still working? (Check-up)

Open the setup program again, tap Owner tools and Check now: it looks at the router, the coin box, the update list and the print server, and says what to do about anything red. It changes nothing.

Something went wrong

Tap Try again: it is always safe, and the router keeps what is already done. The full list of messages and fixes is in the setup guide; doing it all by hand is in the advanced part of the setup guide.
