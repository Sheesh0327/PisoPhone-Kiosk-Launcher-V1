Add a print server

Optional. With a print server, the Wi-Fi page shows a Send a file to the owner button. Files wait in your print server's inbox; nothing prints by itself.

You need: the print server (release 2.2.0 or newer) running on a computer on the router's network, by default at 10.0.0.95, and the router already set up.

  1. Install the print server on a computer plugged into the router. Note the admin password it prints once.
  2. On the print server, show the router key: cat /etc/webprint/send.key (one line).
  3. On the router (ssh root@10.0.0.1), save that line in /etc/coinslot.d/send.key and run chmod 600 /etc/coinslot.d/send.key.
  4. Wait a minute. The button appears on the coin page. If the print server is not at 10.0.0.95, set SEND_HOST in /etc/coinslot.conf.
  5. Try it from a phone on the customer Wi-Fi and open the Inbox bar on the print server's admin page.
Switching it off. In the router console under Settings, Send a file to the owner is On or Off. Deleting the key file also hides the button. Limits: 10 MB per file and 5 files an hour per device; files are deleted from the inbox after 24 hours.

Copying the key by hand is temporary: a connect button that stores the key for you is planned, and this page will change when it ships.
