Universal APK Sideloader

Directly install any APK from your computer to your Android device via WebADB.

1

Enable USB Debugging

Before sideloading, your device must be ready:

  1. Go to Settings > About Phone.
  2. Tap Build Number 7 times quickly to become a developer.
  3. Go back, open Developer Options.
  4. Enable USB Debugging.
Connect phone to computer with a USB Data Cable (not charging-only) and allow USB debugging when prompted.
2

Select APK & Install

Choose an APK file from your computer, then connect your device to install it.
