1. Meet the system

TechNet PisoHub is one coin box that runs two services: PisoWiFi (customer Wi-Fi sold by the coin) and PisoPhone (rental phones, with prepaid time cards for regular players). A unit has three parts that work together:

  • The coin box (an ESP32 board with the coin slot). It counts coins, runs the countdown for every phone and serves the dashboard at http://10.0.0.10.
  • The router (OpenWrt). It makes the Wi-Fi networks, gives internet and shows the customer login page.
  • The rental phones (Android). Each is locked as a kiosk. A customer inserts a coin and the phone unlocks for the time they paid for, then locks itself again.

The three Wi-Fi networks

NameForVisible?
PisoKioskYour rental phones. A phone locks itself to this one network only.Hidden; password made by the setup program
PisoCoinBoxThe ESP32 coin box only. Never give this one out.Hidden
PisoWiFiCustomers on their own phones and laptops (the name you chose at setup).Open, shows a login page
TipEach unit gets new passwords. The setup program saves them in a summary file and a printable sheet. Keep those safe: they are your records.

2. What you need

  • The ESP32 coin box board, and a USB data cable (charge-only cables do not work).
  • An OpenWrt router, factory reset (for example the 360T6M), and a modem with internet.
  • A computer to run the setup program (Windows, macOS, Linux, Armbian, Parrot, Raspberry Pi OS), with a network cable to the router. A small Armbian PC with no screen works too.
  • Your own phone or laptop to open the setup page.
  • The rental phones, factory reset.
  • Your admin QR code (see chapter 14), made once on your own computer.

3. Set up a new unit

One program, pisophone_setup.py, does the whole job. It is about 15 minutes per unit.

  1. Download and run it. Get pisophone_setup.py and run python3 pisophone_setup.py (Windows: py pisophone_setup.py). It installs what is missing by itself.
  2. Open the page it prints on your phone, for example http://192.168.1.50:8765, and type the PIN shown in the terminal.
  3. Router step. Reset the router, connect the modem to its WAN port and the computer to a LAN port. The program finds the router.
  4. Settings step. Type this customer's shop name and public Wi-Fi name. Keep the passwords it made, or type your own.
  5. Install step. Plug the ESP32 into the computer by USB, tap Start the installation and wait about 10 minutes. It writes the coin box, sets up the router and pairs them. Keep the USB cable plugged in.
  6. Save your papers. The program saves a summary, a setup sheet and a Wi-Fi join card. Print the sheet and the card. The card holds a password: keep it with your admin QR code.
No monitor?On a small Armbian PC run once sudo python3 pisophone_setup.py --install-service. The page then starts by itself at every boot. cat /var/lib/pisophone-setup/pin shows the PIN again.
Phone cannot open the page?A factory-reset router has no Wi-Fi yet. The setup computer needs a second connection (its own Wi-Fi or another Ethernet port) on a network your phone is also on, or use the computer's own browser at http://127.0.0.1:8765.

Problems during install? Tap Try again: it is always safe and continues where it stopped. The full table is in setup/README.md.

4. Set up the rental phones

Do this for each phone, starting from a factory-reset phone.

  1. On the setup program's Phones step, choose the slot number. It makes a link filled in with this unit's key.
  2. On the rental phone's first welcome screen tap the same spot 6 times. A QR reader opens.
  3. On your own phone or laptop open the link, tap Show the setup code, and scan it with the rental phone. It joins the Wi-Fi, installs PisoPhone and locks itself.
  4. When the phone says One last step, follow it: usually Open the setting and switch on Allow display over other apps. Android Go phones have no such switch: plug the phone into a computer, tap Allow on "Allow USB debugging?" and use Finish over USB on the setup page (Chrome or Edge).
  5. Open the coin box dashboard (http://10.0.0.10), go to Overview and tap Pair… on that slot.

The slot's status turns from Offline to Locked. Repeat with the next slot. A box handles up to 10 phones.

6. The coin box dashboard

On a device on the router's network open http://10.0.0.10 and sign in with the admin password. There are four tabs and a Sign out button.

Overview

  • Stats: Revenue, Phones (x of 10) and Wi-Fi signal.
  • Phones table with a row per slot: Phone, Status (Renting, Locked or Offline), Time left and Battery. Buttons: Pair…, Locate (the phone rings for 1 minute), Unpair, Set up.
  • Add or remove time: choose one phone or All phones, type minutes, tap Add time or Remove time. Use this for refunds, freebies and fixes.
  • Player accounts: see chapter 8.

7. How your customers use it

Renting a phone

  1. The locked phone says "Insert a coin to unlock all applications for a N-minute session."
  2. The customer taps READY FOR COIN. The phone arms the slot (up to 20 seconds) and shows WAITING FOR COIN.
  3. They insert coins. The screen shows Coins inserted: N.
  4. They tap the green DONE button. The phone unlocks and the countdown starts.

While playing, a small floating pill shows the time left. Tap it to open a panel:

  • Battery and memory, brightness and volume sliders.
  • BOOST frees memory. (The TURBO chip is just a label.)
  • HOME goes to the launcher. CLOSE APP needs a second tap and closes the running apps.
  • ADD TIME (DROP COIN) adds minutes without waiting for the end. It says ESP32 OFFLINE if the box is not reachable.

The phone speaks warnings at 5 minutes, 3 minutes, 1 minute and 10 seconds, then counts down the last five seconds and says "Time expired". It then locks itself. A notice reminds the customer to save their work and sign out of accounts.

Using PisoWiFi on their own device

  1. Join PisoWiFi. The login page opens by itself.
  2. Pick a plan, tap Insert Coin and drop coins. They show with a countdown.
  3. Tap Done (or wait 15 seconds with no coin). They are online, with their time and a code.

Only one customer can have the coin window open at a time. The router picks the best combination of plans for the coins paid. Default plans (pesos : minutes), changeable in /etc/coinslot.conf:

TierPlans
Hyper₱5 : 30 min, ₱10 : 60 min, ₱20 : 120 min
Endurance₱1 : 15 min, ₱5 : 180 min, ₱10 : 480 min, ₱20 : 1440 min

8. Time cards (player accounts)

A time card is a printed QR code that holds a customer's minutes, so regulars can bank time and use it on any phone of your unit.

On the phone

  1. On the lock screen tap Have a PisoPhone card? Scan it and hold the card up to the camera. (Switch cameras with Use front camera / Use back camera.)
  2. A new card asks for a name (up to 16 letters or numbers) and says "Welcome! <time> added to your new account."
  3. A returning card says "Welcome back, <name>!" and shows the time on the account.
  4. To stop, the player taps SIGN OUT twice in the pill panel. The unused time is banked and the phone locks.

If the screen stays off 120 seconds while signed in, the player is signed out automatically (a voice warns 30 seconds before). Their time is kept.

Making and selling cards

  1. On your computer make the unit's card key with make_card_key.py, then print cards with make_cards.py. The dashboard's Player accounts section shows your Box ID for printing.
  2. Sell a card for the minutes you wish. Add the time on the dashboard: Player accounts → + Time. Use – Time to remove, Delete to remove an account.
  3. The table shows each card's number and when it was last used.
The card is the keyWhoever holds the card has its time. Tell customers to keep it like cash. Cards are signed so nobody can make a fake one without your card key.

9. Collecting your revenue

The Vendor tab shows your takings. The amounts stay hidden unless you unlock them with your admin QR code.

  1. Open the dashboard, tap Sign out if needed, and on the login page tap Scan admin QR. Photograph your QR code with your phone's camera.
  2. Open the Vendor tab. The revenue unmasks for a 5-minute window.
  3. Open the coin box and take out the money. Count it.
  4. Tap collect to record the collection. The counter restarts, the lifetime total is kept, and the entry goes into the collections history.
  5. Use the split calculator if you share the income with a partner or a host.
Why a QR code?Your code holds a secret key. The box only knows the matching public key, so nobody can read it from the box. The key never leaves your phone; only a signature does. A login session ends after 15 minutes idle or 1 hour at most.

If the count and the cash do not match, check Orphaned payments on the dashboard before you worry.

10. Admin on a rental phone

Opening the admin console

  • Locked phone: tap the shield icon at the bottom of the lock screen (Security Vault).
  • Unlocked phone: press and hold the floating pill for 5 seconds. A buzz confirms.

Enter the Master Admin Password. There is no factory PIN: it is your box's admin password, sent to the phone when it pairs. After 5 wrong tries the phone locks the PIN for 60 seconds, doubling after each further miss up to 15 minutes. A phone that never paired cannot be unlocked.

What the console offers

SectionUse it to
5m Direct BypassUnlock the phone for 5 minutes (also opens a maintenance window)
Lock TerminalLock the phone now
Quick Time AdjustmentsAdd or remove a few minutes with the +/– buttons
Direct App UpdateCheck for Update & Install: updates the phone app
Battery Health & TTSVoice reminders when the battery leaves your chosen range; Test Voice Engine; background videos on/off
DiagnosticsVersion, recent events, Refresh, copy for support
Hidden AppsHide apps from customers (Manage Apps). LAUNCH opens a hidden app and starts a maintenance session.

Tap Exit Admin Console when done.

Maintenance window

A timed window (15 minutes normally; 5 minutes for the bypass) in which Settings, Play Store and the package installer work and Wi-Fi settings can be changed. While it is open the lock screen and pill are hidden so the admin apps can be touched. It ends when the timer runs out or the phone locks. Opening a new one never shortens one already open.

Recovery

The PIN dialog has two recovery options:

  • SYSTEM RECOVERY & ADB HUB (needs the PIN): shows USB debugging and Device Owner status; can re-enable USB debugging, exit kiosk lockdown, open developer options, or de-provision the phone so you can uninstall without a factory reset.
  • SCAN A RECOVERY CODE (REMOVE APP) (no PIN): scan a signed recovery code from the owner. It removes PisoPhone from that phone. Codes expire.
De-provisionThis removes the kiosk lock for good on that phone. Only do it to retire or repair a phone.

The phone's kiosk Wi-Fi name and password are set during provisioning and cannot be edited on the phone.

14. Keeping it safe

  • Admin QR code and its key file (~/pisophone-superadmin.key): anyone with either is super admin on your boxes. Keep them on your own computer and phone; never email or upload them. Back up the key file somewhere private: it is the only copy.
  • Make the QR with python3 scripts/make_admin_qr.py. The first run also writes a public key file; commit that and update every box once.
  • Lost or leaked QR: run make_admin_qr.py --new, commit the new public key, update every box. The old QR stops working once a box is updated.
  • Passwords: one set per unit. Keep the setup sheet and Wi-Fi join card in a safe place; they hold passwords.
  • Never share the PisoKiosk or PisoCoinBox passwords with customers.
  • Backups: keep the saved summaries from the setup computer (Documents/PisoPhone).
