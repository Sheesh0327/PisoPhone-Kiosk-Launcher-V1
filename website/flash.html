PisoPhone Flash a coin box

Install the firmware

Writes PisoPhone onto the coin box's ESP32 from this browser.

This needs Google Chrome or Microsoft Edge on a computer (USB serial).
No firmware is published on this site yet.
You need
  • The coin box's ESP32 board (ESP32-C3 or ESP32), plugged into this computer with a USB data cable.
  • Nothing else. There is no program to install: the page finds the chip and writes the matching firmware.

Log
Done.

The box restarts and joins the router's hidden PisoCoinBox Wi-Fi by itself (the router setup creates it and pairs the box).

Next, on the router (logged in by SSH): wget -qO- https://pisophone.pages.dev/install.sh | sh
