Open this page from your coin box

Phone setup needs the details of your coin box, which its own page passes along. Opened on its own, this page has nothing to set up.

  1. Connect this computer or phone to the same Wi-Fi network as the coin box.
  2. Open the coin box's page (for example http://kioskmanager.local, or its address on the router).
  3. Under Tools, Phone slots, choose Set up a phone or Remove from a phone.

  1. Use a new or factory-reset phone. On the first welcome screen, tap the same spot 6 times until a QR reader opens. (Some older phones first ask to join a Wi-Fi to download the reader.)
  2. Scan the code below with the phone.
  3. The phone joins PisoKiosk, downloads PisoPhone and sets itself up (a few minutes). Accept its screens until it shows PisoPhone's One last step, and do what it says:
    • Most phones: tap Open the setting, choose PisoPhone, turn on "Allow display over other apps", press Back. Then pair the slot on the box's page.
    • Android Go phones (the phone asks for USB), or if the switch is missing or greyed out: plug the phone into this computer, tap Allow on "Allow USB debugging?" (the phone turned it on by itself, so no Developer options are needed), and click Finish over USB below. It grants the permissions, starts the kiosk, turns USB debugging off again and opens the box's page to pair the slot.

The code holds this box's key and the Wi-Fi password. Show it only to the phone you are setting up.

Only for phones that ask for USB on their One last step screen.

USB setup needs Google Chrome or Microsoft Edge on a computer. Use the QR code instead, or open this page in Chrome.
Before you plug the phone in
  • A factory-reset phone with no account signed in (Android allows the kiosk lock only then).
  • Settings > About phone: tap Build number 7 times, then turn on USB debugging in Developer options.
  • Xiaomi / Redmi / POCO: also turn on Install via USB and USB debugging (Security settings). They ask for a Mi account: sign in, turn them on, then remove the account again.
  • A USB data cable. Unlock the phone and tap Allow when it asks about USB debugging.

Removes the kiosk lock and uninstalls PisoPhone from a phone connected by USB (USB debugging on). No PIN is needed.
Tap again to remove the kiosk from the connected phone.
No cable, or the app cannot reach its box? Use a recovery code. On your own computer run python3 scripts/make_recovery_code.py (it signs a short-lived code with your owner key and saves it as a picture). On the phone, open the admin entry on the lock screen, tap Scan a recovery code (remove app) and show the picture to the camera. It works even if USB debugging is off and the box was never reached. Delete the picture afterwards; the code stops working by itself. It cannot be made on this page, because anyone could then remove the app from your phones.
