📶 Kiosk Wi-Fi for this phone

The phone joins the hidden PisoKiosk network by itself and keeps rejoining it; it finds its coin box only there. The password is in the router's setup summary (piso-setup summary, “PisoKiosk Wi-Fi”).

  1. Use a new or factory-reset phone. On the first welcome screen, tap the same spot 6 times until a QR reader opens. (Some older phones first ask to join a Wi-Fi to download the reader.)
  2. Plug the phone into this computer with a USB data cable (now, or any time before step 5).
  3. Scan the code below with the phone.
  4. The phone joins PisoKiosk, downloads PisoPhone and sets itself up (a few minutes). Accept its screens until it shows PisoPhone's One last step. It turns USB debugging on by itself: no Developer options needed.
  5. Tap Allow when the phone asks "Allow USB debugging?", then click Finish over USB below. It grants the permissions, starts the kiosk, turns USB debugging off again and opens the box's page to pair the slot.

The code holds this box's key and the Wi-Fi password: show it only to the phone you are setting up.

No computer at hand? The phone's One last step screen can also open the setting itself.

USB setup needs Google Chrome or Microsoft Edge on a computer. Use the QR code instead, or open this page in Chrome.
Before you plug the phone in
  • A factory-reset phone with no account signed in (Android allows the kiosk lock only then).
  • Settings > About phone: tap Build number 7 times, then turn on USB debugging in Developer options.
  • Xiaomi / Redmi / POCO: also turn on Install via USB and USB debugging (Security settings). They ask for a Mi account: sign in, turn them on, then remove the account again.
  • A USB data cable; unlock the phone and tap Allow when it asks about USB debugging.
Optional: install an APK file from this computer
Removes the kiosk lock and uninstalls PisoPhone from a phone connected by USB (USB debugging on). Needs the admin PIN.
